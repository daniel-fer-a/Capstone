# Origen de las fuentes

- Requisitos: ERS-CCHIA-2026-10-16.pdf y transcripción de la reunión entregados por Daniel. La ERS no se modificó.
- Autorización: copia literal del SQL Modelo 02 recibido. Su hash se conserva en evidencia/referencia_modelo02.sha256; se mantiene su ficha de autoría y uso interno.
- Esqueleto de la aplicación: rama 13.x del repositorio oficial https://github.com/laravel/laravel, adaptada para esta base API. Se incluye la licencia Laravel en terceros cuando forma parte de los componentes recibidos.
- Dependencias: paquetes descargados por Composer y fijados en composer.lock. Sus fuentes y licencias están declaradas en ese archivo; vendor se obtiene mediante composer install y no se distribuye en este ZIP.
- Nuevo módulo y documentación: preparados para revisión del equipo CCHIA. La entrega no publica el software ni resuelve los acuerdos de propiedad intelectual pendientes del proyecto.
